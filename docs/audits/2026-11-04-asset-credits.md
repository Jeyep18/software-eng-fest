# Bagyong Bahay asset credits audit

**November 4, 2026 · 3 Netherite Ingots**

The [file inventory](2026-11-04-asset-inventory.csv) records 1,097 tracked media files and source companions. It identifies 423 normal game dependencies, 143 recording dependencies, 16 test or legacy dependencies, and 5 inactive references. The remaining 510 files are design, marketing, or reference media, or have no runtime reference found. Of all 1,097 files, 824 have a payload in the prior Windows demo.

The original creator could not be identified for 302 file rows, including 261 normal game dependencies. Most of those dependencies are texture maps and components of shared location models. The count is by file, so it includes related maps and variants. Filter **Provenance** for `Unknown original creator`, `Unknown mesh source`, `Filename credit only`, or the candidate statuses to find the files that still need a source match. A credit or download link does not establish permission to redistribute.

## Scope and verification

The inventory covers tracked audio, raster/vector images, fonts, videos, HDR textures, 3D models, and their tracked Blender/glTF binary companions. It includes `game`, `_raw_assets`, `design_previews`, `marketing`, and the root application icon. Godot import sidecars, UIDs, and generated engine caches are evidence for the scan. They do not receive their own asset credit rows.

Use status comes from project settings, reachable scenes and resources, GDScript paths and known runtime resource lookups, and a Godot 4.6.1 dependency probe of 264 resources. The engine probe recovers texture dependencies that only exist in the imported model, including 54 in the gameplay house. `Game` means a normal-run dependency was found. A scene may carry a fallback or preload that is displayed only conditionally. `Dev/recording`, `Test/legacy`, and `Inactive reference` describe separate code paths. `No runtime reference found` is limited to the inspected references.

The package column describes the exact [previously audited Windows demo](2026-11-04-release-readiness.md) from its PCK manifest. It records imported data separately from gameplay references. Both Windows presets use `all_resources`. A `Not found` row means the file was absent from that manifest by path or known import origin. Some source files have equivalent contents baked into another model. The prior manifest predates the credits update and the Inter license notice added to the export presets.

A new local Windows export confirmed that the DZRH recording, Outside ambience with birds, Bates Shower, and both Traveling _Typewriter variants are still packaged. It also includes the [Inter license notice](../../game/assets/fonts/inter/OFL.txt).

Sources were checked using creator pages, asset download IDs, local readmes, font name tables, GLB metadata, and filenames. External searches covered exact IDs and distinctive names, then credited pack and author names. The five legacy audio matches above also had 0.958 to 0.999 waveform correlation with their original Freesound previews after aligning the decoded mono PCM. Public distribution decisions for unresolved sources and user-supplied media still require owner confirmation.
