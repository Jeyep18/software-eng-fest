# Recording sky panoramas

These user-supplied Radiance HDR files are 1024 × 512, copied unchanged from Downloads for the Dev Mode recording presets. Normal gameplay uses its authored sky. `DevCameraEnvironment` loads these textures only when Sunrise Morning or Sunset is selected during recording.

These are the 1K files supplied for this task; strong zoom can reveal their limited resolution. Clear Sunny uses Godot's procedural sky and requires neither panorama.
