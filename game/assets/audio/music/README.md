# Ending music loop

`ending_cinema_loop.wav` is a 34-second looping edit of **Extreme Sad Cinema**
by Samuel F. Johanns, from the existing
`samuelfjohanns-extreme-sad-cinema-12299-SamuelFJohannsPixabay.mp3`.
The original and its existing credit remain unchanged. The intro still uses
the original recording.

The ending edit omits the original fading outro. It contains seconds 2–34,
followed by a two-second equal-power crossfade of seconds 34–36 into seconds
0–2. Source and output are stereo, 44,100 Hz; the output is 16-bit PCM.
A WAV `smpl` chunk marks the entire file as a forward loop, which Godot imports
automatically. No runtime audio processing or extra dependency is required.
