# Bates Shower

This existing repository font supplies the restored main-menu title and tagline.
The typography was recovered from the menu before commit `364e32a`. The owner
confirmed restoring this version and including its font in Windows exports on
November 8, 2026.

The font's embedded name records identify the family as Bates Shower, the designer
as Imagex, copyright Imagex 2012, and the license notice as:

> Free for personal use only

The file remains unchanged. No separate distribution permission document is stored
in this folder. The creator listing recorded in the project's asset audit is
[Bates Shower](https://www.dafont.com/bates-shower.font). Restoring the asset does
not establish broader distribution permission; that remains an owner verification
item before public release. Credits and THIRD_PARTY_NOTICES retain the attribution
and embedded notice.
